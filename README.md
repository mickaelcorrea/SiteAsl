# Site ASL

Site de apresentação da ASL, empresa de montagem e manutenção industrial.

- `index.html`: página única (HTML e CSS no mesmo arquivo)
- `img/`: fotos e logo

## Como ver

Abra o `index.html` no navegador.

## Como publicar no GitHub Pages

No repositório, vá em **Settings > Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/ (root)`.
